# Independent XLSX end-to-end verification

These tests start the **production Docker image**, mount a neutral Vue pack read-only, send JSON through the public HTTP API and open each returned workbook with **openpyxl 3.1.5**. ClosedXML is used only by the service being tested, never by this verifier. Pillow independently decodes embedded PNG drawings. Parser warnings are failures, including warnings about dropped drawings or defined names.

Run from the repository root:

```sh
docker build -t sheetloom:local .
python3 -m venv .venv-e2e
.venv-e2e/bin/python -m pip install -r tests/e2e/requirements.txt
.venv-e2e/bin/python tests/e2e/test_workbooks.py
```

The runner owns and removes its container, uses an ephemeral loopback port, and needs no existing service. `E2E_IMAGE` selects a prebuilt image; `E2E_ARTIFACTS` changes the output directory (default `.artifacts/e2e`). CI runs the suite as `Docker E2E / openpyxl` and uploads resulting XLSX files, JSON errors, runtime metadata, result summary and container logs even when assertions fail. Fixtures contain synthetic data only.

## Scenarios with independent expected results

Each scenario uses a synthetic template included in this repository. Expectations are explicit values and geometry, not snapshots generated by the same serializer.

| Feature | Scenario and assertion |
|---|---|
| Worksheet-local names | `Anchor` and `InputRange` reused on two worksheets remain local, with distinct destinations and no workbook-global name. |
| Deferred row fitting | A later row changes the column width: the earlier fitted row uses final width 20 and height 30.36, not the former narrow-width height. |
| Merged groups and subtotals | Page subtotal follows the entire A1:A3 rowspan; B4 sums B1:B3, with the page break after the subtotal. |
| Repeated headers | Repeated header height consumes space on subsequent pages; footer rows are exactly 4 and 7 in the neutral landscape case. |
| Horizontal print scaling | Horizontal fit scaling moves footer placement: wide columns produce one footer at row 5, narrow columns at 2/4/6/8; no temporary probe sheet leaks. |
| Printing and freeze panes | Both freeze modes, scrolled headers, print ranges, repeated rows, paper sizes and persisted page-break-preview are inspected with an independent reader. |
| Cell types | Invalid typed inputs stay strings, blanks stay blank, valid numbers/bools/dates have real types, and leading-zero/formula-looking text remains literal. |
| Style precedence | Style precedence and merged-range outer border colors/weights survive serialization. |
| Unicode and escaping | Unicode/XML escaping and the deliberate legacy HTML/newline decoding survive the whole Vue boundary. |
| Precision as displayed | Precision option survives ZIP serialization without rounding original values. |
| Embedded images | PNG bytes, dimensions and merged-cell drawing anchors are decoded independently. |
| Vue packs and isolation | Moment setup locale, request-local module state, source assets and URL-shaped text are checked through actual mounted packs. |
| Template failures | Sync and async template failures return safe JSON errors instead of successful partial workbooks; subsequent requests recover. |

Additional scenarios cover filters spanning trailing or fully inherited merged headings, empty tables, all 1,250 rows of a larger table (including formulas and identifiers), concurrent request isolation, invalid worksheet-name recovery, and non-root/read-only container operation.

## What this proves and does not prove

The assertions verify stored workbook semantics with a different implementation. Formula **expressions** are checked, not calculated caches: neither this service nor openpyxl is used as an Excel calculation engine. Pagination tests preserve the documented renderer heuristic; they do not establish pixel-perfect printing in Microsoft Excel. Fonts are controlled by the image. The image collection is `Worksheet._images` because openpyxl has no public drawing-list accessor; the reader version is pinned and PNG contents/anchors are checked explicitly.

The independent reader exposed invalid row-only auto-filter references (`5:5`) that ClosedXML itself could reopen. The renderer now emits explicit cell bounds (`A5:B5`), including headings merged down from prior rows. Red runs also confirmed that non-finite numeric text aborted workbooks and async Vue failures could return partial workbooks; the same E2E cases pass after the fixes.

Reader representation is accounted for explicitly: an omitted OOXML `fitToWidth` means 1, while openpyxl returns `None`. Column widths include Excel padding. For merged border colors, streaming openpyxl reads the stored boundary cells because normal mode reconstructs those cells and can replace their colors; merge geometry and other styles are still checked in normal mode.

## Black-box findings promoted to permanent CI regressions

Six additional test methods reproduce issues using only the public API and documentation. All six failed on that image before fixes (17 failing subcases, no harness errors). They now belong to the same independent-reader suite on every push and pull request:

| Regression | Independent assertion and control |
|---|---|
| A colspan crosses an earlier rowspan | No merged rectangles intersect; a two-column cell moves to `C2:D2` past occupied `B2`, and following text lands in `E2`. The unspanned control still occupies `A2`. |
| Inherited wrap fails to fit | Workbook-, worksheet-, and row-level wrapping produce the same height as equivalent cell-level wrapping. A cell-level `nowrap` override stays at the default height. |
| Images have zero size in a single row or column | `1×1`, `1×2`, `2×1`, and `2×2` image ranges have positive extents and reach the outer cell boundary. PNG bytes remain identical. The earlier `2×2` expectation is deliberately corrected from endpoint `(1,1)` to `(2,2)`. |
| Static backtick asset URL fails | Quoted and substitution-free backtick URL literals read the same mounted file and produce the same cell value. |
| Whitespace-only text is lost | Spaces, tabs, newlines, and nonbreaking spaces remain text; the empty string remains blank. |
| Leading apostrophe is removed | Names beginning with an ASCII apostrophe, a lone apostrophe, doubled apostrophes, and formula-like text preserve their exact string values. Internal and typographic apostrophes provide controls. |

The E2E pack uses ordinary Vue interpolation and source imports. These tests inspect actual HTTP responses with openpyxl; they do not call the renderer implementation or reuse its expected-value calculations.
